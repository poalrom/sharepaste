# Sharepaste

End-to-end-encrypted clipboard sync between a person's own machines. See `CONTEXT.md` for the domain
glossary and `docs/adr/` for architectural decisions.

## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature-slug>/` (gitignored). See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, used verbatim as the `Status:` value in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
